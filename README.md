# JobFill Lite

本地可加载的 JobFill 版本。

## 用法

1. 打开 Chrome，进入 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择这个 `jobfill` 文件夹
5. 打开任意网申页面，右侧会出现贴边圆形悬浮球，点圆球展开面板
6. 点顶部 `A` 可以自动识别本页字段并填充高置信度匹配项

## 数据修改

推荐直接在右侧面板里点 `✎` 进入编辑模式，字段名和内容都可以改，内容框支持多行。

编辑后会自动保存到浏览器本地存储。改完点 `✓` 回到填表模式。

刷新页面、重新加载扩展、修改扩展代码后，已编辑字段通常都会保留。删除扩展、清空浏览器站点/扩展数据、换 Chrome 用户目录可能会丢失，所以重要内容建议在编辑模式里点「导出备份」。

恢复数据时点「导入备份」，选择之前导出的 JSON 文件。导入会覆盖当前面板里的字段。

如果你换了一台电脑，或者想批量整理初始数据，也可以直接编辑 `resume-data.js`。

多段经历有两种放法：

- 分成多个字段：`项目经历 1`、`项目经历 2`、`项目经历 3`
- 放在一个字段里：在内容框里直接换行，填入 textarea 时会保留换行

## 功能

- 字段分组展示
- 关键词搜索
- 点击字段后自动填入当前输入框
- 面板内编辑字段
- 默认收起为贴边圆形悬浮球，不挡页面内容
- 拖动圆球或标题栏移动浮窗，并记住位置
- 本地规则自动识别页面字段并填充
- 在当前字段上方或下方插入新字段
- 本地自动保存
- 字段备份导出和导入
- 多行内容填写
- 下一个输入框跳转
- 隐私显示切换

## 自动识别

顶部 `A` 按钮会在本地扫描当前页面的 `label`、`placeholder`、`aria-label`、`name`、`id` 和附近文本，然后和你保存的字段名做规则匹配。

自动识别不会联网，也不会自动提交表单。低置信度字段会跳过，避免乱填。
